# Plans

- `<YYYY-MM-DD-name>/` — active plans. One directory per plan: `SPEC.md`,
  `ORCHESTRATOR.md`, `retro.md`, and a folder per chunk.
- `ideas/` — parked ideas awaiting a plan. `/plan:brainstorm <#>` picks one up.
- `completed/` — archived plans. Their retros are read at the start of every new plan,
  so the loop gets better instead of repeating itself.

See `.claude/README.md` for the loop.
